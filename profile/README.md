# VinuChain | VC

VinuChain is a feeless, EVM-compatible Layer 1 network for consumer onchain apps, gaming, payments, and DeFi. It pairs familiar Solidity and Ethereum tooling with DAG/BFT finality and a quota + payback model so stakers and applications can absorb gas friction from everyday user flows.

VC is the native gas and governance coin of VinuChain. Gas fees are accounted for in VC, validators secure the network through staking, and 30% of every VC gas fee is permanently burned.
